# Conveyor Monitoring Dashboard

Conveyor Monitoring Dashboard is a TypeScript application that simulates conveyor monitoring for manufacturing environments.

## Features

- Conveyor speed monitoring
- Downtime tracking
- Productivity calculation
- Chart data generation
- Historical metrics
- Statistics overview
- Configurable settings

## Project Structure

```
src/
  config/
  data/
  models/
  services/
  utils/
```

## Build

```bash
npm install
npm run build
npm start
```
